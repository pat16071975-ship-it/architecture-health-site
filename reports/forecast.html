Прогноз роста

Управленческий сценарий: задайте, что хотите изменить, и сравните три варианта роста. Технические коэффициенты система подставляет из фактических данных и прячет в «Точных настройках».
К отчётам На главную
На сколько месяцев вперёд считаем эффект.

1. База прогноза

Средние показатели одного месяца за выбранный период. Текущий неполный месяц в расчёт базы не входит.

2. Что хотим изменить

Три сценария заполняются независимо. По умолчанию все изменения равны нулю.

3. Что получим

«Станет» — один месяц к концу горизонта. Накопительный эффект — сумма за весь выбранный период.

4. Управленческий вывод

Короткая подсказка по окупаемости и мощности. Это не заменяет подробный расчёт ниже.

Подробности расчёта

По направлениям и по месяцам — только если нужна детализация.

Как считается прогноз

1. База. Берутся только полные месяцы выбранного периода. Абсолютные показатели переводятся в средний месяц. Текущий неполный месяц показывается отдельно и в базу не входит.

Коэффициенты базы. Повторные на 1 первичного считаются как все повторные периода / все первичные периода; средняя выручка на визит — вся выручка периода / все визиты периода; ФОТ % — суммарный расчётный ФОТ периода / суммарная выручка периода. То есть это не среднее из месячных коэффициентов.

2. Новый поток. Указанное дополнительное количество добавляется в каждый месяц горизонта. Повторные рассчитываются из фактического коэффициента и выбранного распределения.

Доп. визиты = новый поток + новые повторные
Загрузка = (текущие визиты + доп. визиты) / мощность
Доп. выручка = доп. визиты × средняя выручка / визит
Доп. прибыль = доп. выручка − ФОТ − мед. затраты − доп. маркетинг

3. Мощность. В сценарии можно отдельно добавить количество доступных приёмов в месяц. Если расчётная загрузка выше 100%, система показывает предупреждение, но не обрезает выручку автоматически.

4. Результат. «Выручка/прибыль в месяц к концу горизонта» берёт дополнительный эффект последнего месяца. «Дополнительная прибыль за горизонт» суммирует дополнительный эффект всех месяцев.

Важно. Три сценария не имеют скрытых автоматических коэффициентов «хуже/лучше». В каждом сценарии используются только те изменения, которые вы ввели сами.
