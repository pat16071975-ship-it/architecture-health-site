## Источник и публикация

База Git — ветка уже опубликованных цен fix/azmednsk-initial-prices-20261012, commit976cbd06aa5f5dc47da7e6dfbeef0dca4d2200a6. PR составляется в эту ветку, без merge. Скрипт применяет только точные преобразования к свежей live-копии с проверкой SHA256 до и после. Цены пяти специалистов уже установлены и сохраняются.

Самостоятельный скрипт tools/apply_critical_20261012.py содержит тот же manifest, что ops/critical_20261012_manifest.json. --check: только проверки, без записи. --apply: только после отдельного разрешения владельца, на az-server от root. До применения проверить SHA256 скачанного из точного commit скрипта.

Установка: предварительная проверка всех исходников; backup исходных файлов с метаданными и списком отсутствовавших файлов; повторная проверка от параллельного изменения; атомарная запись отдельных файлов; HTTPS через локальный nginx для всех80 файлов, контроль отсутствия серверного X-Robots-Tag noindex/none на индексируемых HTML. При ошибке — откат записанных файлов; новый sitemap удаляется, если раньше отсутствовал.
