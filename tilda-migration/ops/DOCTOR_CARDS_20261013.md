# Стаж в карточках специалистов

Прямое поручение владельца от 13.10.2026: выровнять стаж по нижнему краю карточек, как у Чиркова, и поставить Чиркову 21 год.

## Изменение

- Главная: 4 строки стажа; «О клинике» и «Команда»: по 14 строк. Стаж вынесен в отдельный элемент после описания, свободное место над ним распределяется через flex. Нижний отступ карточки сохранён.
- Отдельный файл `/assets/az-doctor-cards-20261013.css` подключён только на этих трёх страницах. Правила действуют при любой ширине; существующие колонки, мобильные размеры шрифтов и отступов сохранены. Нет фиксированной высоты текста или абсолютного позиционирования строки.
- Чирков: 21 год в трёх карточках и на персональной странице. У других специалистов числа не меняются. У трёх зубных техников стаж не указан — новые значения не добавлены.
- Фото, кадрирование, ссылки, имена, специальности, фильтры, цены, логотипы и преимущества сохраняются.

## Установка

Установщик `tools/apply_doctor_cards_20261013.py` меняет только четыре HTML и добавляет один CSS. Не выкладывать `public` целиком: историческое содержимое Git отличается от живого сайта.

Проверяются точные SHA исходных файлов после PR88, пять защищённых страниц с ценами, правовые цитаты, thank, уже исправленные Любаева/стельки и общие CSS/JS. Применяются общий flock, резервная копия `doctor-cards-*`, атомарные замены и проверка пяти HTTPS-ресурсов через локальный nginx с правильным SNI. При ошибке файлы восстанавливаются, новый CSS удаляется. Повторный запуск безопасен.

## Проверки и границы

- На изолированной копии живых файлов: применение, повторный запуск, сохранность остальных файлов, откат при ошибке проверки, отказ при неизвестном исходном HTML и конфликте имени CSS.
- Сравнение DOM: все 38 карточек сохраняют фото, ссылки, фильтры, имена и специальности; 32 строки стажа вынесены вниз; единственное изменение текста — Чирков 20 лет → 21 год. Структурированные данные не меняются.
- Это не подтверждение визуального результата на рабочем сайте. После установки требуется внешняя проверка HTML/CSS и отображения карточек на широкой и узкой странице, включая переключение фильтров.
