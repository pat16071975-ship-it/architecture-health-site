# Перенос длинных слов в карточках — 13.10.2026

Основание: прямое разрешение владельца «Разрешаю исправить перенос длинных слов в карточках». База: PR90, commit `501949b2f678f98cef0ec3f48d40591f4288a053`.

## Изменение

На узком экране длинные слова в ФИО и должностях выходили за ширину текста и обрезались карточкой. Ранее это воспроизведено в браузерном iframe шириной 320 px для «Александрович» и «Миофункциональный».

Новый `assets/az-doctor-cards-wrap-20261013.css` сохраняет все правила выравнивания стажа из PR89 и добавляет наследуемое `overflow-wrap: anywhere` с `word-wrap: break-word` для старых браузеров. Перенос происходит только при нехватке места. Размер шрифта, колонки, фотографии и содержимое не меняются.

Три HTML меняют только адрес этого CSS: главная (4 карточки), О клинике (17), Команда (17). Новое имя файла предотвращает использование закешированной версии CSS. Старый файл сохраняется для отката. Фильтры команды не затронуты.

## Установка

Только `tools/apply_card_wrap_20261013.py --apply` на `az-server` через согласованную команду VS Code. Установщик самодостаточен. Полный checkout `public` публиковать нельзя: историческая ветка отличается от live.

Точные SHA256 свежего live после PR90 включены в manifest. Проверяются 17 защищённых ресурсов, в том числе пять цен, фото и профиль Можаровой, профиль Казанцева, стаж Чиркова, прежний CSS карточек и общие стили/скрипт. Четыре ранее утверждённых фото дополнительно проверяются на неизменность байтов в рамках установки.

Перед записью: блокировка, проверки исходников, резервная копия. После записи: точное совпадение локальных и HTTPS-байтов трёх HTML и нового CSS. При ошибке — автоматический откат записанных файлов и удаление нового CSS. Повторный запуск безопасен.

## Проверка

Локальные проверки установки, идемпотентности, сохранности посторонних файлов, отката при сбое HTTPS, отказа при изменённом исходнике и конфликте имени нового CSS — PASS. Четыре старых изображения в тесте представлены синтетическими байтами: это проверка сохранности, не визуальное сравнение фото.

Новая версия ещё не опубликована и не получила визуальную приёмку. После вывода установки: независимо получить четыре ресурса, проверить реальное отображение карточек на ширинах 320/390/430 и на компьютере, нижнее выравнивание стажа и фильтры команды. Браузерный iframe не заменяет физический телефон.
