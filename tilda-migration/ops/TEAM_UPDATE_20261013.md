## Установка и проверка

`tools/apply_team_update_20261013.py` меняет четыре HTML и добавляет один JPEG. Фото включено в скрипт и проверяется SHA256; дополнительных скачиваний во время установки нет. Полный каталог `public` из Git не выкладывать.

Установщик проверяет живые исходные файлы после PR89, создаёт резервную копию `team-update-*`, использует общий flock, атомарные замены и проверку пяти HTTPS-ресурсов через локальный nginx. При ошибке восстанавливает HTML и удаляет новый JPEG. Защищены пять страниц с согласованными ценами, четыре ранее утверждённых фото, главная, стаж Чиркова, CSS карточек, общие CSS/JS, правовые цитаты и предыдущие текстовые исправления.

Проверки на изолированной копии: применение, повторный запуск, сохранность остальных файлов, откат при ошибке проверки, отказ при неизвестном HTML и конфликте нового файла. Сравнение DOM проверяет порядок, сохранность всех карточек и фильтров, единственные разрешённые текстовые и фотоизменения. После установки требуется внешняя и визуальная проверка на основном сайте.
