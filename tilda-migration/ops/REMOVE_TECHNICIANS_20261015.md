# Удаление отдельных страниц зубных техников

Владелец 15.10.2026 отменил предложение о доработке трёх профилей: отдельные страницы техников не нужны ни на компьютере, ни на телефоне. Основа пакета — принятый PR106, commit `543988b723ca046de456d950906ed351f735df6b`.

## Изменения

- Удалены HTML-профили Казанцева, Палунина и Можаровой в `public/team/tproduct/`.
- На `/team/` и `/o_nas/` шесть ссылок-обёрток заменены обычными блоками. Фото, имена, должности, порядок 17 карточек, фильтры и 14 ссылок на врачей на каждой странице сохранены.
- Два узких CSS-правила внутри этих страниц сохраняют прежний flex-контейнер карточки и поведение фото. Общие CSS/JS, размеры шрифтов и медиазапросы не меняются. Одно HTML-содержимое используется на всех устройствах.
- Из `sitemap.xml` удалены только три адреса: остаётся 74 URL.
- В единственный HTTPS server `azmednsk.ru`, обслуживающий подтверждённый public-root, добавляются девять точных `location =`: для старого адреса без слеша, со слешем и `/index.html`. Каждый возвращает HTTP301 на `https://azmednsk.ru/team/`, в том числе при наличии query. Профильный контент по этим адресам больше не выдаётся. Правила HTTP→HTTPS и www→основной домен сохраняются.

Маршруты перечислены в `remove_technicians_20261015_manifest.json`. Точный блок nginx — `nginx/technician_redirects_20261015.conf`; он предназначен для server-контекста и устанавливается скриптом, а не отдельным глобальным include.

## Установка

Скрипт `tools/apply_remove_technicians_20261015.py` самодостаточный, без загрузки исходников и Git checkout во время применения. Рабочий сайт меняет владелец готовой командой в терминале VS Code на `az-server`; перед ней отдельный `sudo -i`, если ещё не root.

Проверки до записи: hostname/root, общий lock, 6 исходных файлов, 86 защищённых ресурсов, четыре дополнительные ранее утверждённые фотографии, активный nginx и успешный `nginx -T`. Конфигурация находится по активному списку `nginx -T`: необходим ровно один server с именем `azmednsk.ru`, TLS:443 и точным root `/var/www/azmednsk-test/tilda-migration/public`. Меняется только его конфигурационный файл внутри `/etc/nginx`; внешние TLS include читаются для контроля сохранности. Неизвестная структура, дополнительный домен, конфликт существующего location, смешанное состояние или изменение исходников останавливают установку.

Резервная копия: `/var/backups/azmednsk/remove-technicians-*`, шесть файлов public, исходная конфигурация nginx, путь/хеши конфигурации и manifest. Затем добавляется блок переходов, выполняются `nginx -t` и reload; меняются две страницы и sitemap, удаляются три HTML. Права и владельцы сохраняются. HTTPS проверяет точные байты обновлённых ресурсов и главной, все девять старых адресов и три адреса с query. Проверяется сохранность защищённых файлов и других загруженных конфигураций.

При ошибке записанные файлы восстанавливаются, удалённые профили возвращаются, исходная конфигурация nginx восстанавливается и перечитывается. Отдельно выводится результат отката. Повтор успешно установленного пакета выполняет проверку без записей и reload. Каталоги профилей могут остаться пустыми; содержимое страниц удалено. Полный public не выкладывать, PR не сливать.

## Проверки подготовки

Свежие 92 публичных ресурса совпали с принятой базой PR106; добавлены контрольные SHA фото Казанцева и Палунина. Разница Git/live до правки сохранена: обе версии получают одинаковые точечные замены, а installer использует именно live SHA.

Изолированно пройдены 14 проверок: состав/порядок карточек, фото, стаж, фильтры и ссылки врачей; точные 3 удаления sitemap; отсутствие оставшихся публичных ссылок/метаданных на удалённые профили; parser nginx с комментариями/кавычками/несколькими доменами; запрет конфликтов и изменённого установленного блока; применение и повтор без записи; восстановление всех файлов и конфигурации при имитации ошибок HTTPS, nginx и удаления; отказ при изменении любой из 6 целей, CSS/цены или symlink; распознавание внешнего TLS include без его изменения.

Это испытания в изолированной файловой копии с имитацией reload/HTTPS, не проверка реального nginx сервера до установки. Фикстуры четырёх дополнительных старых фото — синтетическая проверка неизменности байтов. Реальные `nginx -t` и HTTPS обязательны в установщике.

До установки сняты исходные замеры 17 карточек на двух страницах при ширинах 320/390/640/1363 в браузере на основном сайте. Приёмка новой версии в браузере выполняется после вывода владельца: 3 старых адреса ведут на команду, у техников нет ссылок/фокуса, 17 карточек и фильтр «Зуботехники» сохранены, геометрия и фото соответствуют исходной версии. Физический телефон и все браузеры не заявляются проверенными.

Справка по синтаксису: https://nginx.org/en/docs/http/ngx_http_core_module.html#location и https://nginx.org/en/docs/http/ngx_http_rewrite_module.html#return.

Остальной аудит и SEO не входят в пакет. Прежнее предложение достраивать профили техников отменено решением владельца.
