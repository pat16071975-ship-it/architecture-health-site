# Загрузка шрифтов и первого фото — 13.10.2026

Основание: «Разрешаю исправить загрузку шрифтов и главного фото».
База: PR93, commit `1f957c8389e8f88e91dced06be719b79bf01351f`.

## Изменение

В девять существующих правил `@font-face` Montserrat в `fonts.css` добавлено `font-display: swap`: браузер может показывать текст запасным шрифтом, пока загружается фирменный. Все семейства, начертания, веса и исходные URL TTF сохранены. Версия CSS `3d16ea7238b5` добавлена к ссылке `/fonts.css` на всех 78 страницах, где файл уже был подключён: 77 публичных страниц и служебная `/thank/`. У `/404.html` этого подключения нет; она не изменяется.

У единственного первого фото главной `/assets/4d67d8e3617de3463719.jpg` заменено `loading="lazy"` на `loading="eager" fetchpriority="high"`. Это указание браузеру начать загрузку без откладывания и повысить приоритет; оно не гарантирует конкретное улучшение LCP. Остальные изображения сохраняют прежние атрибуты. Сам файл фото не изменяется.

После загрузки Montserrat типографика остаётся прежней. До загрузки допускается краткое отображение запасного шрифта — согласованный смысл `swap`. CSS размеров, отступов, сетки, мобильной адаптации, все тексты, цены, фотографии, порядок команды, стаж, canonical, robots, sitemap и JavaScript сохранены.

## Установка

Владелец запускает готовую команду в терминале VS Code на `az-server`. `--check` выполняет проверку без записи; `--apply` создаёт резервную копию в `/var/backups/azmednsk/loading-*`, затем атомарно обновляет файл шрифтов и HTML. Перед записью проверяются hostname/root, общая блокировка, точные SHA исходников и защищённых ресурсов.

HTTPS-проверка требует HTTP200 и точных байтов всех 79 целевых ресурсов через локальный nginx с проверкой TLS, в том числе CSS с новой query-версией. `/thank/` сохраняет `noindex`; проверка запрета индексирования относится только к публичным HTML. При техническом сбое автоматически восстанавливаются уже записанные файлы, включая CSS. Повторная установка безопасна. Новых сетевых загрузок исходников и Git checkout во время применения нет.

Четыре старых портрета представлены синтетическими байтами — это проверка сохранности, не визуальный тест фотографий.
