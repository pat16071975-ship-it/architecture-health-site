# Canonical на 75 страницах — 13.10.2026

Основание: «Разрешаю исправить canonical на 75 страницах».
База: PR91, commit `cc9216fbe8ff0cf62d98a2917e75d4ca74078fe1`.

## Изменение

У 72 публичных страниц canonical указывал на адрес без завершающего слеша, который возвращает 301 на ту же страницу со слешем. В этих тегах добавлен слеш. У трёх страниц зубных техников canonical отсутствовал — добавлен указатель на действующий конечный адрес.

В каждой из 75 страниц меняется только один `<link rel="canonical">` в `head`. Реальные URL страниц, меню, Open Graph, JSON-LD, тексты, цены, фотографии, CSS, JavaScript и адаптивная вёрстка не меняются. Главная и протезирование уже имеют правильный canonical; `/thank/` и `/404.html` служебные. Эти четыре HTML не входят в изменения.

Существующая карта сайта содержит 77 публичных URL. После пакета у каждой из этих страниц будет ровно один canonical на соответствующий URL из sitemap. Фактическая индексация и выбор canonical поисковиком отдельно не подтверждаются этим изменением.

## Проверка исходников

Снимок действующего сайта получен после установки PR91. Для 72 прежних canonical проверен настоящий 301 на конечный URL с HTTP 200. Три недостающих указателя ведут прямо на проверенные страницы с HTTP 200. Подробные адреса и цепочки — `canonical_20261013_review.json`.

Файлы Git и live исторически различаются. Код Git изменён точечной заменой тегов относительно PR91. Установщик применяет эти же замены к точным текущим live-файлам; весь checkout `public` выкладывать нельзя.

## Установка

Самодостаточный `tools/apply_canonical_20261013.py --apply` запускается владельцем в терминале VS Code на `az-server`. `--check` проверяет исходники без записи. SHA256 скрипта и pinned commit включаются в готовую команду.

До изменения: проверка hostname/root, общей блокировки, точных SHA256 исходников и защищённых ресурсов, резервная копия в `/var/backups/azmednsk/canonical-*`. Затем отдельные атомарные замены 75 HTML, проверка точных байтов всех 75 страниц через локальный HTTPS nginx и сохранности защищённых файлов. При техническом сбое — автоматический откат записанных HTML. Повторный запуск безопасен.

Четыре ранее утверждённых портрета дополнительно проверяются на неизменность байтов во время установки. Новый портрет Можаровой, оба CSS карточек, общие CSS/JS, robots, sitemap и четыре неизменяемых HTML защищены SHA256. Сохранность цен, должностей, стажа, команды и всего остального содержимого изменяемых HTML проверяется сравнением всех байтов за исключением canonical.

## Приёмка

Локальный тест проверяет 75 точечных изменений, совпадение всех 77 canonical с sitemap, неизменность остальных байтов, установку, повторный запуск, откат при сбое HTTPS и отказ при изменённых исходниках/защищённых файлах. Четыре старых портрета представлены в тесте синтетическими байтами — это проверка сохранности, не визуальное сравнение.

На момент подготовки пакет ещё не установлен. После вывода владельца требуется независимая внешняя проверка 75 HTML, единственности/адресов canonical и соответствия sitemap. Изменение не затрагивает отображение страницы; проверка поискового индекса относится к следующему этапу.
