# Версия layouts.css

Одобрено пользователем 12.10.2026: «Разрешаю исправить обновление CSS».

Причина: сервер отдаёт актуальный layouts.css после PR82, но наблюдавшийся браузер использовал старую таблицу стилей. В 75 HTML-документах, подключающих layouts.css, URL меняется на `/layouts.css?v=66d783981822`. Версия — первые 12 знаков SHA256 установленного CSS. Сам CSS не меняется. Страница thank сохраняет noindex; три tproduct и 404 не подключают эту таблицу.

Git-версия сайта отличается от действующего сайта. Поэтому установка выполняет только точную замену URL в проверенных по SHA256 живых файлах. Нельзя выкладывать public целиком из этой ветки.

Установщик `tools/apply_css_version_20261012.py --apply` требует root на az-server. До записи проверяет все исходные хеши, CSS, robots, sitemap и три tproduct, а также HTTPS-ответ версионированного CSS. Создаёт резервную копию в `/var/backups/azmednsk/css-version-*`, сохраняет владельцев и права. После записи проверяет HTTPS всех 75 страниц и сохранность четырёх фото. При ошибке откатывает записанные файлы, если их не изменил другой процесс. Общая блокировка совпадает с установщиком PR82. Переключение отдельных файлов атомарно; всего сайта — нет.

Проверка: `python3 tilda-migration/tools/test_css_version_20261012.py <каталог-снимка-сайта-после-PR82>`. Проверены точность 75 замен и сохранность остальных байтов, повторная установка, откат после искусственной ошибки HTTPS, отказ при изменённом исходном файле. Тестовые фото используются только для проверки сохранности байтов. Версионированный CSS на действующем HTTPS возвращает 200 и ожидаемый SHA256. Визуальная проверка браузера выполняется после установки.

При будущих изменениях CSS необходимо обновлять версию ссылок. Этот пакет не меняет процесс сборки и не настраивает автоматическую версионизацию.
