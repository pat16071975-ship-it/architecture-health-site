## Установка

Скрипт `tools/apply_content_corrections_20261013.py` самостоятельный: запуск на `az-server` от root с `--check` или `--apply`. Для установки использовать pinned commit и SHA256 из сообщения владельцу.

Установщик проверяет SHA256 исходных/целевых четырех файлов, сохраняет резервную копию, применяет только указанные замены, проверяет HTTPS через локальный nginx с SNI azmednsk.ru и при ошибке возвращает записанные файлы. Изменение исходников или дополнительное нерассмотренное упоминание бесплатности останавливает применение. Цены пяти специалистов, главная, thank, правовые цитаты и четыре ранее утверждённых фото сохраняются.

Полную папку Git public на рабочий сервер не выкладывать: ветка содержит исторические отличия от live. Требуется точечный установщик.

## Проверка

`python3 tilda-migration/tools/test_content_corrections_20261013.py /path/to/fresh-live-snapshot`

Проверяются применение, повторный запуск, отсутствие изменений остальных файлов, откат при искусственном сбое проверки, отказ при изменённом исходнике и при дополнительном рекламном обещании бесплатности. Фото в тесте представлены синтетическими байтами для проверки сохранности. После запуска владельцем необходима внешняя проверка четырёх страниц; подготовка PR не является публикацией.
