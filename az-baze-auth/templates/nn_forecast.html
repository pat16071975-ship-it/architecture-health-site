Прогноз роста

Один контур: флебологическая клиника целиком. База строится по полным месяцам, а сценарии показывают, как дополнительный поток первичных может перейти в лечение, последующие визиты и оборот.

Загрузка базы…
На сколько месяцев вперёд считаем эффект.
Загрузка текущих данных…

1. База прогноза

Средние показатели одного месяца за выбранный период. Текущий неполный месяц в базу не входит.

2. Что хотим изменить

Три сценария независимы. По умолчанию изменения равны нулю.

3. Что получим

«Станет» — один месяц к концу горизонта. Накопительный эффект — сумма за весь горизонт.

4. Управленческий вывод

Вывод строится только из плана, заданной мощности и введённых экономических параметров.

Подробности расчёта

Помесячная расшифровка выбранного сценария.

Точные настройки

Фактические коэффициенты система подставляет из выбранной базы. Мощность, ФОТ и переменные медицинские затраты автоматически определить из текущих источников нельзя — их можно задать вручную.

Без мощности загрузка не рассчитывается.
Прибыль появится только после заполнения ФОТ и медзатрат.
Как считается прогноз

1. База. Используются только полные месяцы. Все показатели приводятся к среднему месяцу. Текущий неполный месяц показывается отдельно и в базу не входит.

2. Поток. В каждый месяц горизонта добавляется указанное число первичных. Ожидаемое лечение считается через фактическую конверсию выбранной базы. Новые повторные распределяются по выбранной кривой.

Новые лечения = новые первичные × конверсия
Доп. визиты = первичные + лечения + новые повторные
Доп. выручка = первичные × их выручка + лечения × их выручка + повторные × их выручка
Прогноз оборота = средний оборот базы + дополнительная выручка
Загрузка = (визиты базы + доп. визиты) / заданная мощность
Доп. прибыль = доп. выручка − ФОТ − медзатраты − маркетинг

Важно. ФОТ, переменные медзатраты и мощность не подменяются условными коэффициентами. Пока они не заданы вручную, прибыль или загрузка соответственно не рассчитываются.
